# AI Ops Consulting Mind Map

An interactive mind map of a simple AI operations consulting system that anyone can replicate.

The method maps a small business's processes, uses Notion as the database, automates the repetitive work with n8n, runs email and storage on Google Workspace, and uses Claude to build the workflows and run agentic tasks through Projects.

## View it

Open the live page: `https://<your-username>.github.io/<repository-name>/`

Click any node to open its details. Use Previous and Next to walk through every step.
